# LLM 阿里云函数调用地图示例

这个项目演示了如何使用阿里云的通义千问大模型（Qwen）结合高德地图 API 来实现自然语言查询地理位置信息的功能。
需要自行申请高德地图API Key和阿里云百炼API Key

## 功能

- 根据地点名称获取其地理坐标（经纬度）
- 搜索指定坐标附近的兴趣点（POI）
- 通过自然语言与大模型交互，实现智能地理位置查询

## 文件说明

- `llm-aliyun_fc_map.py`: 主程序文件，包含与大模型交互和地图 API 调用的逻辑

## 环境依赖

- Python 3.x
- requests
- openai (用于与阿里云百炼平台兼容)

## 配置

在使用前，需要配置以下信息：

1. 高德地图 API Key：在代码中设置 `amap_key` 变量
2. 阿里云百炼 API Key：在 `llm_function_calling` 函数中设置 `api_key` 参数

## 使用方法

运行程序：

```bash
python llm-aliyun_fc_map.py
```

程序将执行一个示例查询："南京航空航天大学将军路附近的照相馆"，并输出结果。

## 核心函数

### get_location_coordinate(location, city)

根据地点名称和城市名获取其地理坐标。

### search_nearby_pois(longitude, latitude, keyword)

搜索指定坐标附近包含特定关键词的兴趣点。

### llm_function_calling(messages)

调用阿里云通义千问大模型，支持函数调用。

### do(prompt)

处理用户输入的自然语言查询，并与大模型交互获取结果。

## 工作原理

1. 用户输入自然语言查询
2. 大模型理解查询意图，并决定是否需要调用函数
3. 如果需要调用函数，程序会执行相应的地图 API 调用
4. 将函数调用结果返回给大模型
5. 大模型综合所有信息生成最终回复
